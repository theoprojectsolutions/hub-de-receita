# Hub de Receita

Aplicação web responsiva para gestão comercial e lançamento de vendas Claro Empresas.

## Recursos

- Perfis de Vendedor e Admin
- Wizard de vendas PF/PJ
- Catálogo de fibra e planos móveis
- Dashboard analítico
- APIs mockadas para autenticação, planos e pedidos

Site publicado: https://hub-de-receita-claro.comet-cloud-6965.chatgpt.site

O código-fonte completo está disponível no arquivo hub-de-receita-source.zip deste repositório.
